🛒 PrimeBasket

PrimeBasket is a React-based e-commerce application built to provide a simple and user-friendly online shopping experience.

Features
- View product details
- Filter products
- Manage shopping cart items
- Interactive user interface

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Installation and Setup
1. Clone the repository:
   git clone https://github.com/PRaganjali/prime-basket.git

2. Open the project folder:
   cd prime-basket

3. Install dependencies:
   npm install

4. Start the application:
   npx json-server --watch src/jsondata/appdata.json --port 4000
   npm run dev
